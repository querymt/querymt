# Tasks

Conventions used below:

- `RT` stands for `-p querymt-agent-runtime --features remote,oauth,plugin-loaders,api` (the `cargo t-runtime` and `cargo cl-runtime` aliases use the same set).
- `cargo t-agent` and `cargo cl-agent` need `QMT_UI_DIST` pointing at a directory outside `target/` that holds the minimal dashboard fixture described in `.github/actions/rust-setup/action.yml` (`index.html` and `querymt-ui.json`).
- Scenario references are written `<capability> / <Scenario name>`. Each scenario test is named after its scenario in snake_case.
- Tests that create symbolic links or change directory permissions are `#[cfg(unix)]`.
