# Tasks

Conventions used below. They are reference text, not tracked tasks.

- Features: `F=dashboard,oauth,zbus-secret-service,systemd-credentials,remote` (the CI set in `.github/workflows/test-agent.yml`). The zbus and systemd features only take effect on Linux; on macOS those paths stay unverified.
- `QMT_UI_DIST` points at the fixture created in 1.1.
- "Run `<filter>`" means `cargo nextest run -p querymt-agent --features "$F" -E 'test(/<filter>/)'`.
- A group gate runs, in order: `cargo check -p querymt-agent --features "$F"`, the group's filters, `cargo fmt -p querymt-agent -- --check`, `cargo clippy -p querymt-agent --all-targets --features "$F" -- -D warnings`.
- Scenario tests are named after the scenario in snake_case. Runtime-level tests go in `crates/agent/src/api/agent_tests.rs` and drive a real `Agent` with the scripted-provider helpers of `crates/agent/src/agent/delegation_loop_tests.rs`.
