Line count (design D12). Run from `crates/agent-runtime/src`. It prints the non-test lines in scope and the size of the test drivers file. Every group check from group 3 on records both numbers next to the baseline of task 2.4.

```sh
count() { awk '/^#\[cfg\(test\)\]$/ {p=1; next} p && /^(pub(\(crate\))? )?mod [a-z0-9_]+ \{$/ {s=1; p=0; next} {p=0} s {if ($0 ~ /^}$/) s=0; next} {n++} END {print n+0}' "$1"; }
total=0
for f in middleware/*.rs agent/execution/*.rs agent/execution_context.rs agent/session_actor.rs; do
  [ -f "$f" ] || continue
  case "$f" in *_tests.rs|*/tests.rs) continue ;; esac
  total=$((total + $(count "$f")))
done
echo "non-test: $total"
echo "test drivers: $(wc -l < test_utils/drivers.rs)"
```
