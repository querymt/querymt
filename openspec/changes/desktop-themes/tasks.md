# Tasks

All commands run from the workspace root. `cargo t-gpui` is
`cargo nextest run -p querymt-gpui --bins`; `cargo cl-gpui` is the CI
clippy run; `cargo r-gpui` runs the app. Spec references are to
specs/desktop-themes/spec.md. Colour comparisons in tests use a small
tolerance helper, never `==` on floats.
